# OpenMP scheduling trade-offs — Group 3

This project studies the trade-off between scheduler selection cost and execution quality for OpenMP workloads.

[Read the final paper](deliverables/current/IEE_Budgeted_OpenMP_Scheduling_Selection_Time_Compute_and_Execution_Quality_Tradeoffs_group_3.pdf).

Authors: Shaan Chopra (240905140), Mrinal Dhami (240905026), and Aniket Verma (240905156).

The `tradeoff/` directory contains the experiment, current measurements, analysis, and paper source. `src/experiment.cpp` and `scripts/` contain shared implementation and training code; `data/calibration/` holds the training measurements. See [the experiment guide](tradeoff/README.md) for dependencies and build details.
